### Case study: CEO Exchange client-ops platform

One internal platform that runs a marketing agency's client work, from the first sales conversation to the monthly report.

- **Sales pipeline** that tracks every deal from lead to signed client
- **Contracts** sent and signed through DocuSign
- **Billing** through Stripe
- **Client onboarding** that collects what the team needs to start the work
- **Automated reporting** that pulls from Google Analytics 4 and Search Console
- **AI-written client reports** built on that data

**Stack:** Cloudflare Workers, D1, R2, Browser Rendering, and Access, with a Hono API and a React + TypeScript frontend. Tested with Vitest and Playwright.

**Results:**
- 2,000+ automated tests
- A second CRM I built, used by about 21 staff across 4 showrooms

Company-owned, so the code isn't public. Happy to demo it live.
